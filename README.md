# NV Office

Браузерная система управления бухгалтерской компанией.

## Этап 1

- адаптивная главная страница;
- разделы «Сегодня», «Клиенты», «Задачи», «Правила»;
- локальное сохранение тестовых данных в браузере;
- подготовлена структура для подключения Supabase;
- подготовлена SQL-схема первого релиза.

## Публикация

Проект рассчитан на GitHub Pages. После включения Pages приложение будет доступно по адресу:

`https://nadyakunina36-maker.github.io/nv-office/`

## Важно

Не размещать в репозитории секретные ключи Supabase, пароль базы данных, service_role или иные закрытые данные.
